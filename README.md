# 🌐 My Portfolio

A modern, responsive, and interactive personal portfolio built with **Next.js**, **TypeScript**, **Framer Motion**, and **Three.js**.

🔗 **Live Demo:**  
[my-portfolio-2ea2.vercel.app](https://my-portfolio-2ea2.vercel.app/)

---

## ✨ Features

- Modern and clean UI
- Fully responsive design
- Smooth animations with Framer Motion
- Interactive 3D scenes using Three.js
- Project showcase section
- Contact section
- Optimized for performance
- Deployed on Vercel

---

## 🛠️ Tech Stack

- **Next.js**
- **TypeScript**
- **React**
- **Tailwind CSS**
- **Framer Motion**
- **Three.js**
- **Vercel**
